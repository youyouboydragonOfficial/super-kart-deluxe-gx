## 🎮 操作方法

| 操作 | キー |
| :--- | :--- |
| **アクセル（前進）・ロケットスタート** | `W` または `↑` （カウントダウン「2」が小さくなるタイミングで長押し） |
| **ブレーキ（減速・急停止）** | `S` または `↓` （※バックはしません） |
| **ステアリング（左右旋回）** | `A` / `D` または `←` / `→` （滑らかな速度適応ステアリング） |
| **ホップ ＆ ドリフト（3段階ミニターボ）** | 曲がりながら `Shift` / `Ctrl` / `K` （青 ➔ オレンジ ➔ 紫） |
| **ジャンプアクション（空中トリック）** | ジャンプ台の先端で `Shift` / `Ctrl` / `Space` |
| **アイテム使用 / 前投げ** | `Space` または `Z` （長押しで後ろ引きずり防御） |
| **アイテム後ろ設置 / 後方投げ** | `X` または `↓ + Space` |
| **オリジナル必殺 OVERDRIVE (100%時)** | `E` （反重力ホバー変形＋EMP衝撃波） |
| **バックミラー（後方視点）** | `R` (長押し) |
| **フルスクリーン切替 / サウンド切替 / 一時停止** | `F11` / `M` / `ESC` |

## 🚀 起動方法 ＆ ビルド方法

### 1. リリース済み Windows アプリ (`.exe`) をそのまま起動
GitHub Releases からダウンロードして起動できます。過去のバージョン（`v1.0.0`, `v2.0.0`, `v2.0.1`）もすべて保持・アーカイブされています。
- **最新版 Ver 2.0.2**:
  - **インストール不要ポータブル版**: `SuperKartDeluxeGX-Portable-NoInstall-v2.0.2.exe`
  - **セットアップインストーラー版**: `SuperKartDeluxeGX-Setup-Installer-v2.0.2.exe`

### 2. ソースコードから起動・ビルド
```bash
npm install
npm start
# Windows EXE パッケージング
npm run dist
```
