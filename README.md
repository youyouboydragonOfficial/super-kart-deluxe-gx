- **ロケットスタート**: カウントダウン「2」のタイミングからアクセル長押しで開幕爆発ダッシュ！

  - コーナーでドリフト維持すると火花が **青（ミニターボ）➔ オレンジ（スーパーミニターボ）➔ 紫（ウルトラミニターボ）** に進化！

  - 重量級キャラ（クッパ・ワリオ等）やEMP衝撃波でライバルを壁へ叩きつけることが可能！

### 3. 大量アイテム投擲・後方バナナ設置・壁反射こうら
- 🍌 **バナナ / トリプルバナナ**: **後ろに設置（`X` または `↓+Space`）** も **前方への大遠投（`Space` / `Z`）** も両方可能！

- 💣 **ボムへい**: 前方投擲＆後方設置対応！カウントダウン後に周囲のライバルをまとめて吹き飛ばす特大爆発！
- 🍄 **ダッシュキノコ / トリプルキノコ / 👑パワフルダッシュキノコ**
- ⭐ **スーパースター（完全無敵＋高速＋体当たり撃破）**
- ⚡ **サンダー（全ライバル落雷スピン＋アイテム消滅＋ミニ化減速）**
- 🚀 **キラー（巨大弾丸に変身してコース沿いに超音速オート突撃）**
- 🌌 **【オリジナル】グラビティ・ブラックホール**: コース上に重力渦を発生させ、周囲のライバルを吸い寄せて壁に激突させる！
- 💠 **【オリジナル】ハイパーEMPショック**: 電磁パルスで周囲の罠を全破壊し、近くの敵を壁へ弾き飛ばす！
- 🔥 **カオス大量放出キー (`C` キー)**: いつでもワンボタンでバナナ・ミドリこうら・アカこうら・ボムへいを周囲に大量放出！

## 🎮 操作方法

| 操作 | キー |
| :--- | :--- |
| **アクセル（前進）・ロケットスタート** | `W` または `↑` |
| **ブレーキ / バック** | `S` または `↓` |
| **ステアリング（左右）** | `A` / `D` または `←` / `→` |
| **ホップ ＆ ドリフト（3段階ミニターボ）** | 曲がりながら `Shift` / `Ctrl` / `K` |
| **アイテム使用 / 前方に投げる** | `Space` または `Z` |
| **アイテムを後ろに置く（後方バナナ設置 / 後方発射）** | `X` または `↓ + Space` |
| **オリジナル必殺 OVERDRIVE 発動 (100%時)** | `E` |
| **【特盛】バナナ＆反射こうら一斉大量放出** | `C` |
| **強力アイテム即座補充** | `V` |
| **後方視点カメラ（バックミラー）** | `R` (長押し) |
| **フルスクリーン切替 / サウンド切替 / ポーズ** | `F11` / `M` / `ESC` |

## 🚀 起動方法 ＆ ビルド方法

### 1. リリース済み Windows アプリ (`.exe`) をそのまま起動
GitHub Releases から `SuperKartDeluxeGX-Portable-v1.0.0.exe` をダウンロードしてダブルクリックするだけでインストール不要で遊べます。

### 2. ソースコードから起動・ビルドする場合
```bash
npm install
npm start
# Windows EXE ビルド
npm run dist
```
