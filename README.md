# 🏎️ SUPER KART DELUXE GX (マリオカート完全再現 ＋ オリジナル超ギミックエディション Ver 2.0.1)

本物のマリオカートシリーズ（Mario Kart 8 Deluxe 等）の機能・物理・駆け引き・グラフィックディテールを徹底追求した Windows ネイティブデスクトップアプリ（`.exe`）です。

## 🚀 Ver 2.0.1 最新アップデート（操作性向上・壁スライド・衝突バグ完全修正）

ユーザーのフィードバックに基づき、レース中のストレス要因を徹底的に解消しました！

1. **⛔ 逆走・後退（バック）機能の完全廃止 ＆ 前向きスマートアシスト**:
   - バック走行を完全廃止し、ブレーキ（`S` / `↓`）は純粋な減速・停止機能に限定（最低速度は `0` にクランプ）。
   - コース進行方向から75度以上逸脱しそうになると、自動的にスムーズに進行方向へとステアリングをガイドする「Smart Direction Guard」を搭載。逆走に迷い込むことが一切なくなりました。
2. **🛡️ マリオカート8DX式「ウォールスライド」物理**:
   - 壁に激突した際に速度がゼロになって立ち往生する現象を完全解消。
   - 壁接触時もコース進行方向（接線方向）に沿ってスムーズに滑りながら前進を継続（最低26km/h以上を維持）。
3. **🔊 スタート時の接触挟まり ＆ スピーカー轟音・音割れバグの完全修正**:
   - スタート直後に曲がった際、カート同士が挟まって動けなくなり、衝突音が毎秒数百回重なってスピーカーから轟音が鳴り響くバグを根本解決。
   - レース開始直後4秒間は反発係数をマイルドなソフトコリジョンに制御し、スムーズなスタート展開を実現。
   - 衝突音生成にクールダウン（320ms）を設け、大音量の音割れ・スピーカー破損リスクを完全に防止。
4. **🏎️ 快適なスピード感 ＆ 圧倒的に曲がりやすいハンドリング向上**:
   - 150ccの最高速度を以前の過剰な超高速（110〜120）から、コントロールしやすい適正速度（58〜64）へと最適化。
   - ハンドリング旋回性能を大幅に引き上げ、ヘアピンカーブでも思い通りにグイグイ曲がれる極上のドライブフィールを実現！

## ✨ Ver 2.0 新機能・本物再現アップデート

### 1. 🏎️ 1000倍リアル進化した本格3Dレーシングカート＆ドライバー
- **実車レーシングカート＆マリオカート8DX完全準拠の流線型エアロフレーム**:
  - フロントノーズコーン＆チンスポイラー、エンブレムバッジ（各キャラのイニシャルロゴ M/L/P/B/Y等）。
  - サイドポンツーン（エアインテーク・レーシングストライプ）、リアディフューザー、ダウンフォース大型リアウィング。
  - レーシングバケットシート、GTスポーツステアリングホイール、デジタル液晶メーター、デュアルエキゾーストパイプ。
- **前輪ステアリング連動 ＆ タイヤリアルタイム回転**:
  - ハンドル操作に合わせて前輪のステアリングナックルがリアルに左右最大±30度切れます。
  - 走行速度に応じて4輪のスリックタイヤとブレーキローターが正確に前後に高速回転。
- **車体サスペンションロール＆ピッチング**:
  - コーナリング時の遠心力による車体ロール、加速時のリアスクワット、ブレーキング時のノーズダイブを実装。
- **ドライバーのライディングモーション**:
  - 両手でステアリングを握り、コーナリングやドリフト時にイン側へ激しくハングオン（体重移動）。
- **反重力ホバーモード（Anti-Gravity 変形ギミック）**:
  - 反重力ゾーンやオーバードライブ発動時、4輪のホイールが90度水平にパタンと倒れ、ホイール内側の青い光輪（LEDリング）が発光して浮遊！

### 2. ❓ 本物と同じアイテムボックス（？ブロック）＆ ダブルアイテムスロット
- **無限アイテム完全廃止・コース上の？ボックス接触のみで獲得**:
  - レース開始時はアイテムは空っぽ。コース上に浮かぶ半透明虹色クリスタルキューブ（？ボックス）に触れて初めてアイテムルーレットが回転！
  - **マリオカート8DXと同じダブルアイテムボックス＆2スロット管理**:
    - スロット1（メイン大枠）とスロット2（リザーブ小枠）を搭載。
    - 1個目を使い切ると、2個目がスライドして即使用可能に。
  - **ルーレット早止め**:
    - `Space` または `Z` キーを連打することでルーレットを高速停止・即使用可能！
  - **順位別確率テーブル**:
    - 1位はコインやバナナ、下位になるほどアカこうら、スター、キラー、サンダー、トゲゾーこうら等の逆転アイテムが出現。

### 3. 🛡️ アイテム後ろ引きずり防御（後方こうらガード）
- バナナ、こうら、ボムへいを所持している際、`Space` または `Z` キーを長押しすると、**カートの真後ろにアイテムを引きずったまま走行**できます。
- 後方から迫るアカこうらやミドリこうらが引きずっているアイテムに命中すると、**相殺されて完全防御**！カートは無傷で走行を続けられます！

### 4. 💨 スリップストリーム（Drafting）急加速
- 前を走るライバルの真後ろ（スリップストリームゾーン）を1.3秒間キープして追走すると、風のエフェクト＆風切り音とともに「SLIPSTREAM!!」が発動し、強烈な急加速ブーストで一気に追い抜くことができます！

### 5. ✨ ジャンプアクション（空中トリック）
- ジャンプ台や段差から飛び出す瞬間に `Shift` / `Ctrl` / `Space` を押すと、ドライバーが空中で360度スピン＆ポーズ！
- 着地時に「ミニターボダッシュ」が発生します！

### 6. 🪙 コインシステム＆被弾ドロップ
- コイン1枚につき最高速度が1%アップ（最大10枚で10%アップ）。
- クラッシュやトゲゾー被弾時にはコインが3枚コース上に飛び散り、跳ね返って誰でも拾い直せます。

## 🎮 操作方法

| 操作 | キー |
| :--- | :--- |
| **アクセル（前進）・ロケットスタート** | `W` または `↑` （カウントダウン「2」で長押し） |
| **ブレーキ（減速・急停止）** | `S` または `↓` |
| **ステアリング（左右）** | `A` / `D` または `←` / `→` （前輪ステアリング連動） |
| **ホップ ＆ ドリフト（3段階ミニターボ）** | 曲がりながら `Shift` / `Ctrl` / `K` （青 ➔ オレンジ ➔ 紫） |
| **ジャンプアクション（トリック）** | ジャンプ台の先端で `Shift` / `Ctrl` / `Space` |
| **アイテム使用 / 前投げ** | `Space` または `Z` （長押しで後ろ引きずりガード） |
| **アイテム後ろ設置 / 後方発射** | `X` または `↓ + Space` |
| **オリジナル必殺 OVERDRIVE (100%時)** | `E` （反重力ホバー変形＋EMP衝撃波） |
| **バックミラー（後方視点）** | `R` (長押し) |
| **フルスクリーン切替 / サウンド / ポーズ** | `F11` / `M` / `ESC` |
