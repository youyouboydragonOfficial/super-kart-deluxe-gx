## 🚀 Ver 2.0.3 最新アップデート（邪魔なトラップ全廃・横向き完全禁止・壁滑走強化）

ユーザーのフィードバックに基づき、レース中のストレス要因を完全に排除しました！

1. **🧹 ぐるぐる回る邪魔なトラップ（ファイアバー・障害物）を完全撤去**:
   - コース上に設置されていた回転ファイアバー（FIREBAR）やドッスン（THWOMP）などの邪魔なトラップを全廃！
   - コース上には快適なダッシュボード（加速板）、スーパージャンプ台、反重力加速リングのみを残し、純粋なレースの駆け引きとコーナリングに100%集中できます！

2. **🛡️ 壁に激突しても止まらない！超高速ウォールスライド＆内側バウンス**:
   - 壁接触時にカートの向きを即座にコース進行方向（壁と平行）へと揃え、壁の外側へ向かうステアリング入力を自動カット。
   - 壁に当たっても減速せず、最低 44km/h（または現在速度の98%）の超高速を維持したまま火花を散らして前進を継続！「壁にぶつかって止まってしまう」現象を完全に根絶しました。

3. **🧭 「最大横に向くのも完全禁止」＆ スマートステアリングアシスト**:
   - コース進行方向に対するカートの傾き角を **最大 ±38度以内（約0.66rad）** に厳格にリミット！
   - どんなにハンドルを切っても **真横（90度）を向くことが物理的に 100% 不可能** になりました。
   - カートは常にコース前方（ゴール方向）を向いて走るため、間違った方向に進んで時間をロストすることが絶対にありません！

## 🎮 操作方法

| 操作 | キー |
| :--- | :--- |
| **アクセル（前進）・ロケットスタート** | `W` または `↑` （カウントダウン「2」が小さくなるタイミングで長押し） |
| **ブレーキ（減速・急停止）** | `S` または `↓` （※バックはしません） |
| **ステアリング（左右旋回）** | `A` / `D` または `←` / `→` （滑らかな速度適応ステアリング） |
| **ホップ ＆ ドリフト（3段階ミニターボ）** | 曲がりながら `Shift` / `Ctrl` / `K` （青 ➔ オレンジ ➔ 紫） |
| **ジャンプアクション（空中トリック）** | ジャンプ台の先端で `Shift` / `Ctrl` / `Space` |
| **アイテム使用 / 前投げ** | `Space` または `Z` （長押しで後ろ引きずり防御） |
| **アイテム後ろ設置 / 後方投げ** | `X` または `↓ + Space` |
| **オリジナル必殺 OVERDRIVE (100%時)** | `E` （反重力ホバー変形＋EMP衝撃波） |
| **バックミラー（後方視点）** | `R` (長押し) |
| **フルスクリーン切替 / サウンド切替 / 一時停止** | `F11` / `M` / `ESC` |

## 🚀 起動方法 ＆ ビルド方法

### 1. リリース済み Windows アプリ (`.exe`) をそのまま起動
GitHub Releases からダウンロードして起動できます。過去のバージョン（`v1.0.0`, `v2.0.0`, `v2.0.1`, `v2.0.2`）もすべて保持・アーカイブされています。
- **最新版 Ver 2.0.3**:
  - **インストール不要ポータブル版**: `SuperKartDeluxeGX-Portable-NoInstall-v2.0.3.exe`
  - **セットアップインストーラー版**: `SuperKartDeluxeGX-Setup-Installer-v2.0.3.exe`

### 2. ソースコードから起動・ビルド
```bash
npm install
npm start
# Windows EXE パッケージング
npm run dist
```
